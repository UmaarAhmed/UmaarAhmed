## ⚡ Engineering Principles I Ship By

<table>
<tr>
<td width="50%" valign="top">

### 🏗️ **Architecture Over Frameworks**

I choose foundations that survive years, not hypes that fade in months. Next.js 15, Supabase, and Vercel aren't accidental choices — they're bets on long-term maintainability.

### 🎯 **Ship Fast, Ship Correct**

Production-grade from day one. No "we'll fix it later." Every commit is deployed, monitored, and hardened.

If it's not instrumented, it doesn't exist. Analytics, error tracking, performance budgets — standard in every project.
